Welcome to the notebook. Keep one topic or investigation per note.

## Write a note

1. Open [the editor](/admin/ ':ignore') and sign in with GitHub once OAuth is configured.
2. Choose **Notes → New Notes**, add a title and body, and optionally upload a file.
3. Publish the note to save it to the main branch.
4. Edit `_sidebar.md` on GitHub and add a link such as `- [My note](/notes/my-note.md)`.

The title becomes the initial filename slug. Check the actual filename in GitHub when adding a sidebar link. Published changes appear after Pages finishes deployment.

## Attachments

Use the optional File field to upload a reference file. Its download link appears below the published note. You can also insert links in the body using Docsify's bypass syntax:

```markdown
[Download reference](/notes/files/reference.pdf ':ignore')
```
